# Data Mining & ML Classification Suite

Team project for a Data Mining course, comparing classification algorithms and measuring how preprocessing choices affect accuracy.

## What this does

- Implements and compares Decision Tree, SVM, and Random Forest classifiers on a real-world dataset
- Compares `MinMaxScaler` vs. `StandardScaler` preprocessing and measures the effect on model accuracy
- Visualizes data distributions and the impact of outlier removal (before/after boxplots, pairplots)

## Results

90%+ predictive accuracy across the compared models.

## Tech stack

Python · scikit-learn · pandas · matplotlib/seaborn
